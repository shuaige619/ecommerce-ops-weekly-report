## 安装与使用

```sh
git clone https://github.com/shuaige619/ecommerce-ops-weekly-report.git
cd ecommerce-ops-weekly-report
```

将此目录按宿主支持的方式登记为本地 Skill，或把 [SKILL.md](SKILL.md) 交给支持 Agent Skills 的助手读取。保留 `scripts/`、`references/` 等配套目录的相对位置；下载完成不代表宿主已加载。

需要能读取本地 Markdown 的 Agent 环境。其他工具与依赖以 SKILL.md 中的要求为准。

## 输入与输出

**输入：** 电商与内容运营的当周数据、对比数据和工作记录。

**输出：** 运营周报及结构化结果。

## 使用示例

```text
请使用 ecommerce-ops-weekly-report 汇总这些周数据，统一统计口径，分开写事实、推测和下周动作。
```

以上是调用示例，不是已完成业务运行的记录。
